# BankPilot Agent

BankPilot 是个人账单核查工具。导入银行、微信或支付宝账单后，可以查找和分类流水、核对重复记录与转账退款、管理预算和固定支出，以及生成和比较月报。

![从账单到核查结果：导入、确认、查询与追溯](docs/assets/product-flow.svg)

账本同时保留原始流水和确认关系后的调整统计。跨月退款按到账日处理，各币种独立计算。助手可查询收支、预算和固定支出，并展示交易证据；预算修改需确认后才生效。

## 使用范围

支持 CSV 和未加密单表 XLSX，单文件不超过 10 MB、5,000 条交易。微信、支付宝适配器按公开字段结构实现，真实脱敏导出文件认证仍待完成；不保证所有历史格式兼容。

系统不登录网银、不读取实时余额、不执行真实资金操作。[飞书私聊机器人与支付宝支付沙箱](docs/INTEGRATIONS.md)默认关闭，沙箱订单不计入账本。
