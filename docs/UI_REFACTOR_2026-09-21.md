# 深色工作区 UI 重构

日期：2026-09-21。基于当前 R2 工作树，未提交、推送或部署。

## 设计依据

使用用户指定的 [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)，执行金融仪表盘设计系统检索、React 与深色对比度指南检索。结合用户选择“保留深色，提升对比度、层次和阅读密度”，采用数据密集型工作区结构；不采用检索结果中不适合账本的营销页布局与手写字体。

- 背景、卡片、浮层分别使用 `#0c1117`、`#161e28`、`#1d2835`；正文 `#edf2f7`、次要文本 `#a6b5c5`，薄荷绿 `#66ddbf` 表达主要操作与净额。
- 保留系统字体和现有 SVG 图标，金额使用等宽数字；输入框与按钮统一边界、焦点和间距。
- 导航分为日常账本与数据核对；总览依次展示金额、核对状态、收支与月度关注、最近流水，来源与计算说明折叠。
- 助手历史区分当前会话、时间和已保存结果；新会话收起历史，历史金额提示重新查询；保留服务端确认和恢复流程。
- 移动端使用顶部导航入口、账本卡片和全屏助手；补充跳到主要内容入口，支持减少动画偏好。

## 验证

- `web`: `npm run lint`、`npm run build` 通过。
- `make verify-interactions`：8 组定向回归通过；Hook 调度器不替代真实 DOM。
- 隔离本地数据库与合成账户：总览支出 6215、收入 18000、净额 11785，10 条流水；预算编辑打开后取消，未提交金融修改。
- 浏览器实测：1440×900 中文总览、桌面预算弹窗与账本、1024×900 英文总览、768×1024 导入页、375×812 账本及助手历史/新会话。检查的窄屏页面未发生横向溢出。
- 配色 token 对比度计算：正文/卡片 14.91:1，次要文本/卡片 8.03:1，次要文本/浮层 7.13:1，主按钮文字/背景 9.06:1；不是完整 WCAG 审计。

本次为界面重构，不改变金额计算、权限或 API。浏览器使用合成数据与固定助手响应，不代表真实模型质量或生产验收；未重新执行完整业务和迁移验收。
