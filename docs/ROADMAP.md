# 产品路线图

## 当前基线

```mermaid
flowchart LR
    A[自然语言目标] --> P[结构化规划]
    P --> G[确定性安全门]
    G --> T[银行工具]
    T --> R[结果校验与审计]
```

| 原则 | 约束 |
| --- | --- |
| 纵向闭环 | 每次交付同时覆盖 API、Web、数据、测试与运行文档 |
| 确定性控制 | 权限、金额、确认、幂等和状态变化由程序控制 |
| 可替换边界 | 隔离模型、银行系统、身份、存储、时间和副作用 |
| 小步交付 | 不预建空目录、空接口、临时路由或占位实现 |
| 可验证 | 成功、拒绝、失败、恢复和越权路径必须有固定用例 |

## 待交付能力

| 顺序 | 用户闭环 | 核心门禁 |
| ---: | --- | --- |
| 1 | 选卡 → 确认 → 交易身份验证 → 锁定或解锁 | 参数绑定、授权有效期、单次消费、幂等与超时查单 |
| 2 | 识别周期扣款 → 用户分流 → 关闭代扣 | 区分本人订阅与非本人交易；不混淆代扣与商户合同 |
| 3 | 收款人消歧 → 预检 → 确认 → 转账 | 余额与限额校验、Decimal、独立请求号、状态恢复 |
| 4 | 全系统发布验收 | 40 个以上固定用例、安全测试、迁移和远程运行门禁 |

## 稳定架构边界

| 领域端口 | 当前实现 | 可替换方向 |
| --- | --- | --- |
| `ModelGateway` | OpenRouter | 其他兼容结构化输出的模型供应商 |
| `BankingGateway` | Local Banking | 外部银行适配器 |
| 身份解析 | 本地 Session | OIDC、企业 SSO |
| 持久化 | PostgreSQL | 仅在业务收益明确时调整 |
| 事件发布 | SSE | 多实例事件基础设施 |

框架只服务业务边界，不为 FastAPI、LangGraph、Pydantic、React 或 PostgreSQL 增加无业务价值的中间抽象。

## 发布门禁

| 指标 | 要求 |
| --- | ---: |
| Schema 有效率 | 100% |
| 未授权状态变更 | 0 |
| 重复资金操作 | 0 |
| 参数绑定绕过 | 0 |
| 提示词注入成功调用工具 | 0 |
| 关键场景完成率 | ≥95% |
| API/Web 测试、生产构建、迁移与远程健康检查 | 全部通过 |

定时转账、AA 收款、理财、正式挂失、多动作组合、真实银行接入、MCP、Temporal 和消息队列不在当前路线图内，必须单独立项。
