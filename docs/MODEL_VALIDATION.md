# 模型验收说明

模型只负责识别意图、选择工具和解释结果。金额、权限、用户隔离与写入确认以服务端结果为准。

真实模型验收须使用获授权的模型和调用额度，在隔离环境执行。逐例记录模型版本、语言、输入、工具选择、参数、回复与判定；分别报告工具准确率、文字质量、无效结果和越权行为。固定网关、合成样本及静态检查不能代替真实模型验收。

覆盖中英文的月度收支、预算、固定支出、跨月／跨年追问、流水查找、双月比较、候选发现、歧义澄清和越权请求。重点检查：

- 区分无导入数据、实际零消费、退款贡献和购买笔数，不能跨币种合计。
- 在歧义时询问必要条件，准确提取月份、分类、币种和账户范围。
- 不用模型文字替代逐笔证据、覆盖提示或用户确认；拒绝未授权写入。
