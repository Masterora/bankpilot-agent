# 模型验证与边界

本文保留模型相关验证信息，不把历史结果视为当前版本认证。模型代码、供应商接入与配置不在本次文档清理范围内。

## 已有模型记录

消费追问阶段曾使用 `google/gemini-2.5-flash` 执行 20 个固定场景，工具范围与无写提案检查全部通过。直接查询、月份/分类/币种追问、零数据、能力澄清及操作拒绝均获得预期工具行为，未发生跨币种合计或未授权写入。逐例输入、回复及判定文件已删除，仅保留历史结论，不能复核为当前版本的通过率。

文字复核接受 18/20。已知问题：

- 无导入流水被表述为“已导入数据中该分类为 0”，混淆数据缺失与零消费。
- 包含退款的 4 条贡献记录被称为“4 笔消费”，混淆贡献条数与消费笔数。
- 简短回复可能省略覆盖条件；确定性金额卡、覆盖范围和逐笔证据仍是核对依据。

## 尚未认证

- 持久会话下的跨月/跨年指代、歧义澄清和文字质量未完成真实模型验收。
- 受限流水查找没有真实模型验收；曾准备的 22 个场景文件已删除，自然语言条件提取质量未认证。
- 双月消费比较未运行中英文真实模型场景；工具选择与月份、币种提取准确率未知。
- R6 助手只读发现已通过确定性工具调用、会话持久化和页面跳转检查。2026-09-29 使用隔离库合成流水与已配置的 `google/gemini-2.5-flash` 执行三条真实模型场景：中英文明确询问截至 2026 年 8 月的月付候选，均选择 `recurring_discovery` 并提取 `2026-08-01`；询问当前未结束的 9 月时返回“请选择已结束的完整月份”，没有读取发现数据。这是三例定向回归，不代表自然语言总体准确率或真实账单质量认证。
- 固定网关、合成数据和确定性接口检查不代表真实模型质量。

后续模型验证仍应分别记录工具选择、参数提取、权限边界和文字质量，不以少量样本或结构检查宣称总体准确率。
