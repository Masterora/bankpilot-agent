# 当前能力与验证边界

更新：2026-10-09。本文描述当前本地代码的能力与验证边界；R7 当前仅本地实现，通知和发现默认关闭，当前代码尚未推送或发布。界面以当前 Web 实现为准。

## 当前能力

- **流水查找**：账本与助手共用确定性搜索服务，支持日期、账户、币种、方向、绝对金额、商户/备注、分类和批次。20 笔分页、全量 CSV、按 ID 详情、双版本检查及跨页核查证据；分类和核查写入拒绝旧修订。独立查找上下文支持保存、并发校验和恢复。

- **账户与账单**：注册登录、账户绑定、CSV/XLSX 识别和字段映射、预览、幂等导入、按操作 key 恢复、分类修正、导出及批次撤销。交易保留来源批次与物理行号，多账户歧义需明确选择。
- **交易核对**：重复、本人转账和退款的候选、人工双边搜索、确认、排除及撤销。只有确认关系影响调整统计，金额按币种与交易日期计算；同批重复限制仍由服务端校验。
- **总览与账本**：分币种收支、导入覆盖、最近流水、预算和固定支出待办。总览、账本和规划期间分别管理，URL 支持恢复；批次入口和助手定位不改变总览期间。总览使用 SQL 聚合，关系候选按需检查。
- **待办状态**：预算与固定支出提醒由服务端生成，可标记已读、按固定期限稍后处理、提前恢复，以及按类型关闭/开启。两组独立降级；状态变化不修改账务事实。
- **站内通知**：R7 六类待办事务事件、租约消费、日期/稍后扫描、认证收件箱及已查看已在本地实现；新增会话的显式查询变化订阅，实际匹配内容变化才提醒，可从收件箱打开查询。默认关闭；完整发布门槛未通过，见 [R7 本地记录](R7_ACCEPTANCE.md)。
- **预算**：月度分类额度、修改、删除、复制上月缺少项、上月支出参考、覆盖范围、剩余与超支、退款原消费证据；并发冲突保留输入，重新确认后才能保存。
- **预算结转**：预算页按已结束的上月读取剩余额度，显式预览并确认；超支不结转、负支出按零计算、缺少本月额度时以上月额度为基础。每个目标月一次，原请求可恢复冻结回执，账本/预算变化拒绝旧确认；不自动重算历史回执。
- **固定支出**：月付/年付、月末/闰年日期、下一期预计日期、按生效月份变更、未来配置修改或取消、暂停/恢复/结束；支持流水预填、候选搜索、关联/解除、连续核对及可撤回的“本期未发生”。未关联不等于漏扣。
- **月付候选发现与建项**：服务端默认关闭；受控启用后可读取最近 12 个完整月的导入流水，并忽略、恢复、关联已有计划或解除关联。候选可编辑草稿，生成 15 分钟冻结提案，再显式确认创建未来的月付计划；请求与确认均可按原身份恢复，历史扣款不自动关联。规则精度未认证。
- **助手与核查**：月度收支、预算、固定支出问答及确认后设置/修改预算。受控启用发现时，可只读汇总已完成月份的候选组数量、规则和覆盖状态，并打开页面证据；模型不接收逐笔发现流水，也不负责建项确认。消费与预算共用金额计算，提供逐笔构成、跨月退款原消费、每页 20 条明细、结构化追问和流水定位。账本修订号与 `spending-v1` 计算版本共同保护证据重读，失效返回 409。日期范围核查保留当时快照与运行记录。
- **会话恢复**：服务端保存完整轮次与当时结果；请求去重、90 秒截止收敛、历史分页、范围恢复、删除及无内容去重记录。历史提案读取当前执行资格，确认仍走确定性预算写入与冻结回执。
- **月报**：后台生成、有限重试、历史摘要、更新提示、冻结证据、新旧版本比较、CSV/JSON 导出、打印入口和删除。历史金额不随账本变化重算；比较限历史列表可取得的同月前一成功版本。
- **账户数据**：设置页独立展示个人数据 JSON 导出与注销危险区域（导出排除密码、会话及共享安全记录），当前密码与 `DELETE` 确认后可注销账户；活动任务阻止注销，已封存的 `UNKNOWN` 只读核查不再阻塞，离线备份不随注销改写。
- **界面**：全页面深色主题、中英文切换、移动端账本卡片与详情侧栏；宽屏助手并排、窄屏模态显示，切换保留输入。设置页提供账户、密码修改、语言、切换账号与退出入口。编辑草稿跨页保留，刷新/关闭有未保存提示。
- **运行保障**：统一错误契约、请求与作业耗时记录、3 秒数据库就绪预算、90 秒助手预算及 120 秒 Web 代理等待；离线备份、还原、核对和恢复准备。工作树结构为 `20261009_0021`（32 张表）。本轮未迁移共享库或发布；新增共享认证/模型限额、SSE 名额、当前密码校验和客户端账户绑定。

金额、权限、用户隔离与写入校验由服务端确定性代码负责。契约见 [架构](ARCHITECTURE.md)，操作步骤见 [运行手册](RUNBOOK.md)。模型相关验证单独保留在 [模型验证与边界](MODEL_VALIDATION.md)。

## 未完成与限制

- 微信/支付宝真实脱敏导出样本认证未完成；合成验收不能证明所有格式兼容，无编号账单的跨文件身份歧义仍存在。
- 候选扩展窗口超过 10,000 笔时停止发现，仍读取完整期间统计和已保存关系；期间本身超限则拒绝查询，不返回截断合计。拆分转账、汇兑及手续费差额不支持自动配对。
- 无限制自然语言或模糊流水搜索、自动确认周期项目、外部提醒未交付；共享预算不在当前路线内。流水查找仅支持有界结构化条件，真实模型提取质量未认证。周期暂停不保存历史暂停区间。
- 模型文字仍可能混淆无导入数据与零消费、贡献条数与购买次数；确定性金额卡和证据为准。20 例结果不能代表总体模型准确率。
- 真机、弱网、原生月份弹层、系统打印/PDF 分页及生产代理专项验收未完成；助手预算确认仅有固定网关、合成提案的浏览器记录，未完成真实模型端到端验收。
- 月报删除/完成竞争、租约耗尽与本地数据库短时中断已定向通过；更长中断、多进程业务全矩阵、加密存储、异机备份、保留策略与代表性恢复目标仍需实际环境确认。
- 大量历史关系与远程链路的 P50/P95、连接等待和 SQL 计划仍需专项测量。
- 生产发布需前后端同批部署、旧协议/规则版本拒绝与线上验收；推送 `main` 可能触发部署。后续功能按 [路线图](ROADMAP.md) 推进。

系统不登录网银、不读取实时余额、不执行资金操作；未导入不代表无消费，净流入不代表余额。
