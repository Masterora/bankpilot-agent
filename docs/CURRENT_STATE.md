# 当前能力与验证边界

更新：2026-09-16。本轮交付包含导入恢复、备份还原与代码整理，尚未发布；本地通过不等于生产验收。

## 已实现

- 注册与会话、账户绑定、CSV/XLSX 识别预览、幂等导入、按 key 恢复、分类修正、导出及批次撤销。交易保留来源批次和物理行号。
- 重复、本人转账和退款关系的候选、确认、排除与撤销；只有确认关系改变调整统计，金额按币种及交易日期计算。
- 总览通过 SQL 聚合返回汇总及最近五笔流水，不读取完整账本或执行候选发现。总览、账本与关系核对共享期间，页面和期间可从 URL 恢复。
- Agent 支持日期范围内全部已导入账单的只读核查，保存当时的证据快照。账户、商户、分类等筛选在账本页完成；Agent 对不支持的筛选明确拒绝。
- 月报支持生成、历史查看、更新提示、JSON 导出和删除；持久任务有限重试，历史快照不随账本变化重算。
- 请求/作业耗时观测、3 秒数据库就绪预算、离线备份/还原/核对/准备命令。恢复按列名与约束语义核对，拒绝冲突连接配置。

数据与事务契约见 [架构](ARCHITECTURE.md)，启动、发布和备份操作见 [运行手册](RUNBOOK.md)。

## 能力边界

微信与支付宝真实脱敏导出样本认证未完成；合成文件仅证明已覆盖规则，不能证明所有格式和状态均受支持。无编号账单的跨文件身份歧义无法仅凭现有字段消除。

候选扩展窗口超过 10,000 笔时停止发现，仍读取完整期间统计与已保存双边证据；期间本身超过 10,000 笔则要求缩短范围。截断集合不得用于金额汇总。拆分转账、汇兑与手续费差额尚不支持自动配对。

周期扣款、预算和自助注销未交付。系统不登录网银、不读取实时余额、不执行银行操作；未导入不代表没有消费，净流入不代表余额。

## 已验证及范围

本地 PostgreSQL 17 隔离数据库与合成账户，2026-09-15 至 09-16：

- 空库迁移、旧批次升级及回退再升级；历史统计保留 null；Alembic check 无新增变更。
- 五个同 key 并发请求只创建一个批次；摘要冲突、编号事实冲突、拒绝计数、撤销重放、新 key 重导、无编号次数、130 条明细截断及用户隔离通过。
- 三种来源表头、未知状态、中性方向、全排除不创建账户、多行字段物理行号、标准分隔符与混合账户拒绝通过。
- Chrome 验证手动映射、预览、提交、历史及提交等待时刷新后找回同一批次。临时 React hook 验证旧操作迟到成功/失败不影响新操作，空文件不遗留加载状态。
- 月报实际生成和 JSON 导出通过。恢复覆盖有剩余重试和已耗尽次数的运行中月报，以及中断 Agent；分别进入排队/失败/未知，旧令牌及会话失效。
- 12 表一致性备份还原、同名 CHECK/类型/空值/默认值变化检测、迁移回退升级后的列编号变化、连接环境冲突提前拒绝、重复 prepare 无额外修改均通过。
- 页面验证覆盖账本期间切换、同期间重复选择、标识复制、Escape 关闭和焦点返回。移动端、慢网及减少动态效果未完成本轮专项浏览器复验。

`make verify`（Ruff、Mypy、ESLint、TypeScript、Vite）和 `git diff --check` 通过。CI 配置另含迁移与镜像构建；这里不代表最新远程 CI 已通过。业务/浏览器验收使用仓库外临时脚本，没有持久自动回归目录。实际模型链路未纳入本轮复验。

## 性能基线

2026-09-15 本地 HTTP，每组预热 10 次、测量 100 次；未加入大量历史关系，未测 SSH/Tailscale 链路：

| 期间交易数 | 并发 | P50 | P95 | 返回体 |
| --- | --- | --- | --- | --- |
| 1,000 | 1 | 9.37 ms | 10.25 ms | 2,080 B |
| 1,000 | 5 | 18.33 ms | 24.00 ms | 2,080 B |
| 10,000 | 1 | 22.76 ms | 23.59 ms | 2,088 B |
| 10,000 | 5 | 28.94 ms | 35.16 ms | 2,088 B |


临时小数据备份约 147 ms、还原与准备约 203 ms，仅为该次演练规模，不代表生产 RPO/RTO。未通过新增缓存、扩大连接池或放宽容量上限获取结果。
