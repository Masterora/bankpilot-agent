更新：2026-09-17。已提交基线为 `129dbb9`；本轮新增固定支出、预算初版及用户流程优化，仍在工作区，尚未提交或发布；本地通过不等于生产验收。

## 已实现

- 注册与会话、账户绑定、CSV/XLSX 识别预览、幂等导入、按 key 恢复、分类修正、导出及批次撤销。交易保留来源批次和物理行号。
- 重复、本人转账和退款关系的候选、确认、排除与撤销；只有确认关系改变调整统计，金额按币种及交易日期计算。
- 总览通过 SQL 聚合返回汇总及最近五笔流水，不读取完整账本或执行候选发现。总览、账本与关系核对共享期间，页面和期间可从 URL 恢复。
- Agent 支持日期范围内全部已导入账单的只读核查，保存当时的证据快照。账户、商户、分类等筛选在账本页完成；Agent 对不支持的筛选明确拒绝。
- 月报支持生成、历史查看、可读摘要、更新提示、流水 CSV / 证据 JSON 导出、打印入口和删除；持久任务有限重试，历史快照不随账本变化重算。
- 请求/作业耗时观测、3 秒数据库就绪预算、离线备份/还原/核对/准备命令。恢复按列名与约束语义核对，拒绝冲突连接配置。

- 周期扣款支持手动月付/年付项目、月末/闰年日期、跨月核对实际支出、解除关联、暂停/恢复及结束；未关联不等于漏扣。
- 月度分类预算支持设置、修改、删除、复制上月缺少项、实时支出/剩余/超支与退款原消费证据。币种分开，已确认重复和本人转账排除。

数据与事务契约见 [架构](ARCHITECTURE.md)，启动、发布和备份操作见 [运行手册](RUNBOOK.md)。

## 能力边界

微信与支付宝真实脱敏导出样本认证未完成；合成文件仅证明已覆盖规则，不能证明所有格式和状态均受支持。无编号账单的跨文件身份歧义无法仅凭现有字段消除。

候选扩展窗口超过 10,000 笔时停止发现，仍读取完整期间统计与已保存双边证据；期间本身超过 10,000 笔则要求缩短范围。截断集合不得用于金额汇总。拆分转账、汇兑与手续费差额尚不支持自动配对。

自动周期识别、外部提醒、预算结转、共享预算和自助注销未交付。周期配置按生效月份保存，未生效且未核对的未来变更可修改或取消；暂停是当前跟踪开关，不保存暂停历史区间。系统不登录网银、不读取实时余额、不执行银行操作；未导入不代表没有消费，净流入不代表余额。

### 用户流程交付与复验

- 总览增加按月预算提醒、待核对和即将到期的固定支出，可定位对应项目；显示已导入账户、最近导入及所选期间最新流水，不推断账期完整。
- 导入增加折叠式来源指引；导入完成和历史批次都能进入本批流水，完成后可继续核对交易关系。
- 账本支出可预填固定支出；候选按商户、金额和日期接近程度排序，仍由用户确认。到期后可确认“本期未发生”并撤回，不生成虚假交易。未来未生效且无核对结果的配置可修改/取消。
- 预算增加上月同分类支出参考、按币种的覆盖范围和到账本核对分类入口。账本按当前分类筛选；跨月退款的原消费证据仍在预算明细查看，两者不是同一证据集合。
