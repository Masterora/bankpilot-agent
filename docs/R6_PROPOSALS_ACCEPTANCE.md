## 仍需验收

2026-09-29 评审修正：冻结提案新增目标账户名称/ID及月付展示；发现开关关闭时保留原请求恢复键，退出登录清理用户暂存并阻止晚到响应回写；重复计划冲突返回本用户目标 ID 供页面打开；新提案提交时压缩过期未确认行，并把同时有效待确认提案限制为 20 个。隔离 PostgreSQL 检查了过期提案压缩、旧请求保留、确认拒绝、20 个同时有效提案限额和同请求回放；两个同组提案并发确认只有一个计划成功，冲突返回目标计划 ID。上述浏览器回归已重新执行。

后续评审修正：提案详情只读投影按当前时间显示过期状态并隐藏草稿，不等待确认失败或下一次创建提案；确认遇到确定性冲突后禁用再次确认，重新查询原提案也保持失效标记。隔离库检查过期详情、已确认回放及读取不改库；真实浏览器检查过期提案无确认按钮，证据版本冲突后确认按钮禁用且重查后仍禁用。`make verify` 与差异检查通过。
