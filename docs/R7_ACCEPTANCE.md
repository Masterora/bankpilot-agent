- 排程在 Asia/Shanghai 每个午夜及当前通知日期范围内 SQL MIN 聚合所得最早稍后截止扫描当前和下一月份，覆盖月首、窗口进入及到期类型变化。领取与执行分事务，执行获取用户与工作行锁后读取当前时间，再校验令牌及租约，过期或超时回滚；90 秒租约、45 秒单次执行预算（不超过剩余租约）、最多五次事件尝试，失败指数退避至 failed，扫描失败保留进度并退避。
- 消费重新校验当前事实、签名、类型、代次、状态修订及偏好，投影通知与完成事件同事务。关闭偏好、已读/稍后、删除和事实失效同步抑制可见通知及未投递事件；再次开启不补投旧事件。
- 认证收件箱、用户绑定的签名游标、幂等已查看接口。已查看不修改 R5 待办。列表及计数共用可重复读快照；超限、失效未同步、扫描迟到超过 60 秒时不显示数字。最多核对 1,000 条未抑制通知，超过此上限返回 incomplete；分页超过 100 页明确拒绝。
- 顶部通知侧栏、中英文、业务定位、可见时每 60 秒刷新及 focus/online/业务写入刷新，业务变化和已查看成功使旧响应失效并排队刷新，分页校验数据版本；退出和账号切换卸载清空缓存；标记失败仍导航并保留错误提示。
- 恢复预览显示旧事件和排程处理数量；恢复准备清除令牌、抑制未完成旧事件、要求新基线，保留通知与 seen_at。沿用原恢复库确认与收据协议。
- 后台通过 uvicorn.error 输出 JSON，记录安全失败码、扫描延迟、事件等待时间、尝试次数及 SQL/总耗时，扫描使用领取令牌作业标识；不记录用户身份、交易内容或 SQL 文本。生产积压告警与代表性 P50/P95 尚未验收。

### 并发、故障与运行保障

- 月报：同时领取只产生一个有效租约；三轮实际删除/完成竞争最终均为已删除且无快照；删除后的旧 worker 无法写回。租约到期重新领取拒绝旧令牌，第三次租约失联收敛失败；实际处理器可重试异常三次后终态失败；完成事务在提交前中断会回滚，原租约再次完成成功。
- 通知：双消费者领取不重复；过期事件租约可回收，旧领取者失败回写不覆盖新令牌；退避时间确实在未来，第五次失败进入终态；扫描双消费者领取及失败保留排程通过。未来提醒 0/1/7/8 天窗口边界通过。
- 丢响应：在服务端成功提交后，由 ASGI 传输层读取并丢弃响应、抛出 ReadError，再以原 payload 和身份恢复。覆盖导入、待办状态、类型偏好、发现提案、助手轮次和月报六类请求；结果与未丢响应主流程一致。这是实际数据库加传输故障注入，尚未覆盖浏览器的全部弱网交互。
- 安全运行控制：共享认证额度、CPU 取消期间保留名额、模型尝试/任务额度（MockTransport，无外部访问）、网关重建不重置额度、配置/密钥混用拒绝、并发租约及默认关闭基线保留通过。SSE 两条等待流不占用数据库连接，第三条被拒绝，会话撤销后关闭并回收连接。
- 基础设施：实际停止并重启本轮独立 PostgreSQL；停止期间 readyz 返回 503、healthz 保持 200，数据库与配置租约恢复后原 API 进程恢复 200。没有执行生产中断演练。
- 迁移与恢复：空库升至 0020、降至 0006、再升至 0020，最终 alembic check 无结构差异。实际 31 表备份/还原及原始核对、恢复预览、清理旧安全租约、保留额度记录和重复 prepare 收据通过。该小样本不证明生产 RPO/RTO。
- 静态门禁：当前 make verify 的 Ruff、Mypy（95 个源码文件）、ESLint、TypeScript、Vite（95 个模块）及脚本语法检查通过。未运行远程 CI 或容器部署验收。

- 账本：按实际执行条件区分筛选无匹配与本期无流水；真实浏览器验证不存在商户显示修改/清除条件，清除后恢复已有流水，历史空账期显示导入或选择其他期间。执行日期、笔数与 CSV 导出合并到同一工具栏。
- 账户筛选：本地代理对账户接口注入 503，页面显示独立错误与实际重试入口；恢复接口后无需重新打开筛选即可读取账户，并保留未提交的 `keep-draft` 搜索文本。
- 通知：首次可用状态读取注入 503 时显示错误与重试入口；恢复接口并重试后显示正常通知按钮和未查看计数。原用户身份、请求版本与晚到响应保护保留。
- 设置：导出与永久注销分开为两个区域，注销使用危险色边框、标题及按钮。浏览器验证展开、错误确认时禁止提交及取消恢复；未在浏览器执行永久注销，删除行为由上述隔离 ASGI 检查覆盖。
