# 验收说明

## 自动化

在仓库根目录运行 `make verify`，检查格式、静态规则、类型、前端构建和部署脚本语法。它不执行数据库回归。

完整回归需要独占、一次性的本地 PostgreSQL。先用 `BANKPILOT_DATABASE_URL` 指定该库，按[运行手册](RUNBOOK.md#数据与配置)迁移至 head，并执行 `alembic check`。再把同一个地址显式设为 `BANKPILOT_TEST_DATABASE_URL`，运行：

```bash
cd api
uv run python -m unittest discover -s tests -v
```

未设置测试地址时，数据库用例会跳过，不能计为通过。测试仅接受回环地址和以 `bankpilot_` 开头的库名；恢复用例会清理目标库的全部登录会话、助手历史和飞书授权。禁止用日常开发库、共享库或生产库运行。CI 在一次性服务数据库上执行完整回归和迁移往返。

现有 24 项回归包括：

- 飞书与支付宝沙箱：加密事件和 RSA2 签名、一次性绑定、用户隔离、去重、并发锁、解绑与恢复撤权、投递重试、下单幂等、查单和退款终态。供应商请求使用替身，支付宝签名使用实际 SDK；不发真实消息或付款。
- 预算模板与月报比较：旧预览拒绝、原请求与冻结回执重放、用户隔离、快照金额和 Decimal 差额。

## 功能验收

使用合成账号、账单和报告，核对当前构建。记录环境、范围及未执行项。

| 范围 | 检查要点 |
| --- | --- |
| 认证与账户 | 登录、跨账号请求拒绝、改密撤销会话与飞书绑定；确认导出不含凭据，注销只在一次性环境验证。 |
| 导入、账本与核对 | 预览、确认、幂等重试、冲突、分类、撤销与跨期退款；缺数据或超限不能误报为零，旧修订不能覆盖新结果。 |
| 账期与固定支出 | 按账户核对、已结束月月结、账本变更后重新核对；覆盖暂停、恢复、结束、未来排程、月末闰年和未知历史。 |
| 预算与月报 | 检查结转、补缺与覆盖的实际结果，过期预览与并发拒绝；核对冻结回执、跨月及不同规则的报告差异和导出。 |
| 助手与待办 | 检查工具范围、证据、会话恢复和显式写入确认。站内通知启用前须覆盖六类事件、跨午夜、并发领取、去重、回滚、关闭后不投递、失败收敛与生产容量。候选发现另须通过[真实样本门槛](ROADMAP.md#固定支出发现)。 |
| 外部接入 | 在本地替身环境核对绑定、独立刷新与错误、沙箱订单确认、查单和状态恢复；验证私网 HTTP 和窄屏。真实平台验收另按[接入说明](INTEGRATIONS.md)。 |
| 恢复与发布 | 在隔离库验证旧数据升级、备份还原、摘要核对、恢复准备与幂等；发布环境另查前后端版本、Cookie、代理、模型及回调链路。见[运行手册](RUNBOOK.md)。 |

中英文、窄屏、键盘和弱网检查使用真实页面；受控 API 替身仅用于对应错误、延迟或重试场景。本地回归和合成数据不能证明真实模型质量、真实账单格式兼容性或生产恢复目标。剩余缺项见[当前状态](CURRENT_STATE.md#未完成与限制)；真实模型和外部平台调用须另行授权。
